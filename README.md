# Path of Exile

A theme for [Omarchy](https://omarchy.org/) inspired by Path of Exile: abyssal
navy shadows, an ember-orange accent, and a pale violet-grey foreground. Active
window borders run from ember orange through arcane violet to cold blue.

## Backgrounds

The wallpapers are official Path of Exile 2 boss artwork released by Grinding
Gear Games for desktop use. They remain the property of Grinding Gear Games and
are not covered by the license below.

## Installation

```bash
omarchy theme install https://github.com/dbohry/omarchy-poe2.git
```

Or, from within an existing checkout:

```bash
omarchy theme set path-of-exile
```
